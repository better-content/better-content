# Better Content Modpack

Better Content is an expert Forge 1.20.1 modpack and its supporting content layer. Custom mod source, ownership, build, and deployment metadata is maintained in docs/custom-mod-workspace.md; every custom mod lives in a sibling repository under /home/dev.

## Community and support

For modpack and mod discussion, playtest feedback, and bug reports, join the [Better Content Discord](https://discord.gg/EkRnZbzqS9).
